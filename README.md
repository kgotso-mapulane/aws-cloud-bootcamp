# AWS Cloud Bootcamp

A hands-on AWS project covering identity and access management, networking, compute, storage, scalability, high availability, and cost management. Each lab builds on the previous environment to apply AWS concepts through practical configuration, testing, and documentation.


## Labs

| Lab | Topic | Status |
|---|---|---|
| [Lab 1 — Account Setup & IAM](./lab-01-account-setup/) | Root account security, MFA, IAM users, groups, roles, least privilege | Completed |
| [Lab 2 — Networking Fundamentals](./lab-02-networking/) | Custom VPC, public and private subnets, Internet Gateway, routing, security groups | Completed |
| [Lab 3 — Compute: EC2 & Serverless](./lab-03-compute/) | EC2 web server, user data automation, IAM role integration, AWS Lambda | Completed |
| [Lab 4 — Storage: S3, EBS & Lifecycle](./lab-04-storage/) | S3 versioning and lifecycle management, EBS volume configuration, snapshots | Completed |
| [Lab 5 — Scalable, Load-Balanced Web App](./lab-05-scalability/) | Launch Template, Application Load Balancer, Auto Scaling, multi-AZ deployment, self-healing | Completed |
| [Lab 6 — Account Budgets & Cost Alerts](./lab-06-budgets/) | Monthly cost budget, actual and forecasted alerts, zero-spend tripwire, Cost Explorer | Completed |


## Approach

Each lab follows a practical build-and-validate approach:
- Design the architecture and identify the required AWS services
- Configure the environment using the AWS Console
- Apply security, networking, availability, and cost considerations where relevant
- Test and verify the expected behaviour
- Capture key console states as evidence of the implementation
- Document the architecture, configuration, testing, and technical observations
